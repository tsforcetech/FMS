# Phase 3 schema

All documents live under `companies/{companyId}` and carry `companyId` and `schemaVersion: 1`. Field definitions for content are authoritative in `packages/shared/src/tasks.ts`.

| Collection                         | Key fields                                                                                                                                                                                                                                                                                                                         | Mutability                                                                       |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| taskCategories                     | code, name, parentId (top-level only), departmentId, description, status                                                                                                                                                                                                                                                           | Master record (Phase 2 contract: code claims, revision, archive protection)      |
| taskTemplates                      | code, name, categoryId, departmentId, defaultPriority, description, status                                                                                                                                                                                                                                                         | Master record                                                                    |
| templateVersions/{templateId}-v{n} | templateId, version, state (draft/published/retired), content, revision, publishedAt/By, retiredAt                                                                                                                                                                                                                                 | Draft editable; published frozen except retirement                               |
| tasks                              | reference, title, templateId, versionId, version, content (snapshot), approvalRequired, priority, siteId, locationId, facilityId, assetId, departmentId, assigneeIds (≤10), teamId, notes, plannedStart, dueAt, status, attempt, draftAnswers, occurrenceKey, cancelReason, exceptionCount, evidencePending, completedAt, revision | Status changes only with a matching event; progress saves only while in progress |
| taskEvents/{taskId}_{revision}     | taskId, revision, action, fromStatus, toStatus, actorUid, at, note, assigneeIds, attempt                                                                                                                                                                                                                                           | Create-only                                                                      |
| taskSubmissions/{taskId}_{attempt} | taskId, attempt, versionId, answers, exceptions, evidencePending, remarks, site/location/facility/asset, submittedBy, submittedAt                                                                                                                                                                                                  | Create-only                                                                      |
| taskApprovals/{taskId}_{attempt}   | taskId, attempt, decision (approve/request_rework/reject), reason, reviewerUid, submittedBy, decidedAt                                                                                                                                                                                                                             | Create-only; reviewer ≠ submitter                                                |
| taskExceptions                     | taskId, attempt, questionId, site/location/facility/asset, type, severity, description, detectedBy, detectedAt, status (open/acknowledged/closed), resolutionNote, revision                                                                                                                                                        | Status and note only                                                             |

`content` (version and task snapshot):

- `title`, `instructions`, `priority`, `estimatedMinutes`, `approvalRequired`
- applicability: `siteTypes`, `facilityTypeIds`, `assetCategoryIds`
- `sections[]`: `{ id, title }`
- `questions[]` (≤100): `{ id, sectionId, label, help, type, required, choices, defaultValue, unit, min, max, expectedMin, expectedMax, criticalMin, criticalMax, showIf {questionId, equals} | null, evidence (none/photo/qr/gps), escalateOnFail }`
- `raci[]` (≤30): `{ id, letter R/A/C/I, kind designation/department/team/employee, refId, label, siteId }`
- `assignment`: `{ mode manual/employee/department/team/shift/site, refId, siteId }`

Answers are stored as strings keyed by question ID (multiple choice joined with `|`). Hidden conditional follow-ups are dropped on submission.
