# Phase 6 schema — attendance and field evidence

| Collection                                     | Fields                                                                                                                                                                                                                                                                                                                                             | Rules                                                                                                                                                                                                                                                                                                           |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `attendance/{employeeId}_{YYYY-MM-DD}`         | companyId, schemaVersion, employeeId, uid, date (local), siteId, shiftId, checkInAt, checkInLocation {lat, lng, accuracy, capturedAt} or null, checkOutAt, checkOutLocation, status (`checked_in`/`checked_out`/`corrected`), lateMinutes, source (`mobile`/`web`), correction {reason, by, at} or null, revision, createdAt, updatedAt, updatedBy | Create: the linked employee only, date must be today, site in scope, `checkInAt == request.time`. Update: check-out once by the same user with server time; or correction by an in-scope supervisor (not for themselves) or an admin, with a reason. Read: own records, scoped supervisors, admins. No deletes. |
| `taskEvidence/{taskId}_{attempt}_{questionId}` | companyId, schemaVersion, taskId, attempt, questionId, type (`qr`/`gps`), refKind, refId, location, capturedAt (device), recordedAt (server), uid, employeeId, status (`verified`/`recorded`)                                                                                                                                                      | Create-only by the assignee while the task is in progress in a scope site; QR must reference the task's own asset, location or facility. Readable with the task.                                                                                                                                                |

Indexes: attendance by employee + date and site + date (187 of 200).

Device-side (never in Firestore): encrypted task snapshot, drafts, queue, place names and photos per user (`fos:{uid}:…`), key in the platform secure store.
